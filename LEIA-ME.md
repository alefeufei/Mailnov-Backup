# LEIA-ME - Mailnov Backup

Consulte o arquivo principal [README.md](README.md) para o guia completo com:
- **Instalação Passo a Passo**: Configuração local no Windows, Linux e macOS.
- **Como Iniciar com 2 cliques**: Uso do arquivo `iniciar.bat`.
- **Guia Completo de Deploy**:
  - Como rodar como Serviço do Windows (NSSM).
  - Deploy em servidor Linux (systemd + Nginx reverso com SSL).
  - Armazenamento em volumes externos (`MAILBACKUP_DATA_DIR`).
- **Automação**: Agendamento de backups automáticos diários.
- **Exportação e Migração**: Uso dos seletores nativos de arquivo para PST, EML, MBOX e migração IMAP com autocura Dovecot.
