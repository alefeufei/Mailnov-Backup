Seeds of the e2e test (`crates/cli/tests/e2e_dovecot.rs`). Each directory below is a folder of the
`origem` account (nested directories are nested folders); `NAME.flags` is an optional sidecar with
the IMAP flags of `NAME.eml`. `../*.eml` are the INBOX messages shared with the core test. The
large-attachment message (~5 MB) is generated by the test itself to keep the repository small.
